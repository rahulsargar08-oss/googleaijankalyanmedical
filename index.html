Supabase SQL Table Definition (`customers`) 
-- 1. Create customers table in Supabase SQL Editor:
CREATE TABLE IF NOT EXISTS customers (
  id BIGSERIAL PRIMARY KEY,
  full_name TEXT NOT NULL,
  mobile_number TEXT NOT NULL,
  address TEXT,
  age INTEGER,
  preferred_doctor TEXT,
  required_tablet TEXT NOT NULL,
  status TEXT DEFAULT 'Pending',
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Enable Row Level Security (RLS) and public access:
ALTER TABLE customers ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public select and insert"
ON customers FOR ALL
USING (true)
WITH CHECK (true);

Connecting your own Supabase project:

  1. Create a free project at supabase.com.
  2. Open the SQL Editor and paste the SQL script above.
  3. Add SUPABASE_URL and SUPABASE_ANON_KEY to your project environment variables.
